# Echo (Офлайн-помощник)

Полностью **офлайн** голосовой помощник для Android, созданный для управления медиаплеером.
Никаких облаков, никаких подписок и слива данных.

## Возможности
- **Офлайн-распознавание**: Работает без интернета на базе [Sherpa ONNX](https://github.com/k2-fsa/sherpa-onnx).
- **Шумоподавление**: Встроенная нейросеть DPDFNet отсекает фоновый шум (шум дороги, вентилятор).
- **Управление музыкой**: Вперед, назад, пауза, громче, тише, максимум, минимум, эхо(активация, чтобы как алиса, приглушао и слушал).
- **VAD (детектор активности)**: Экономит заряд батареи, не обрабатывая тишину в комнате.

## Голосовые команды
| Действие | Фразы |
|----------|-------|
| Следующий трек | «Следующий», «Вперед», «Дальше», «Скип» |
| Предыдущий трек | «Назад», «Предыдущий», «Верни» |
| Пауза / Плей | «Пауза», «Стоп», «Играть», «Продолжить» |
| Громче | «Громче», «Добавь», «Плюс» |
| Тише | «Тише», «Убавь», «Минус» |
| Максимум | «Максимум», «На всю» |
| Минимум | «Минимум», «В ноль» |
| Режим "Эхо" | «Эхо» (приглушает звук на 5 секунд) |

## Как собрать проект
1. Склонируй репозиторий.
2. Помести файл `sherpa-onnx-1.13.8.aar` в папку `app/libs/` (если его там нет).
3. Помести модели в `app/src/main/assets/model/` (encoder.int8.onnx, decoder.onnx, joiner.int8.onnx, tokens.txt, dpdfnet_baseline.onnx).
4. Открой проект в Android Studio и собери (Build -> Make Project).
